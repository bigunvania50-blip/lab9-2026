# Лабораторна робота № 9. Створення простого веб-додатку на Flask/Django

## Мета

Набути практичних навичок у розробці простих веб-додатків з використанням фреймворків Flask та/або Django. Дослідити основи роботи з маршрутизацією, шаблонами, формами та базою даних.

## Початок роботи

### 1. Налаштування середовища

Спочатку налаштуйте своє робоче середовище.

1.  **Клонуйте репозиторій.**
2.  **Встановіть залежності:**
    ```bash
    pip install -r requirements.txt
    ```

### 2. Інструкції для запуску прикладів

У цьому репозиторії є два приклади: один для Flask, інший для Django. Вони знаходяться в директоріях [`src/flask_example`](src/flask_example) та [`src/django_example`](src/django_example) відповідно.

Щоб отримати детальні інструкції щодо запуску кожного прикладу, виконайте наступну команду з кореневої директорії проекту:

```bash
python src/lab9.py
```
Цей скрипт покаже вам, як запустити кожен із прикладів крок за кроком.
