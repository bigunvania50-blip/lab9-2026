## Висновки

Під час виконання лабораторної роботи № 9 я здобув практичні навички розробки простих веб-додатків з використанням фреймворку Flask.

Я навчився:
1. Налаштовувати маршрутизацію (routing) для обробки різних URL-запитів (`/`, `/add`, `/delete`).
2. Використовувати шаблонізатор Jinja2 для динамічного відображення HTML-сторінок (передача змінних, цикли `for`).
3. Працювати з базою даних SQLite через ORM `Flask-SQLAlchemy` (створення моделей, додавання, вибірка та видалення записів).
4. Обробляти дані з HTML-форм (метод `POST`) та перенаправляти користувача за допомогою `redirect`.
